Проект: Аналитическая модель управления доходностью (Yield Management) пассажирского вагона

      Цель проекта: Создание инструмента для анализа юнит-экономики и оперативного управления инвентарем (местами) на маршруте
                    свысокой сменяемостью пассажиров.

      Инвентарная модель (Digital Twin вагона): 
            Разработана динамическая матрица занятости (54 места на 29 перегонов), которая в реальном времени визуализирует
            «пустые» и «забитые» участки пути. Использование Heatmap-анализа позволяет мгновенно определять локальные просадки
            спроса для принятия маркетинговых решений.
            
      Алгоритм гибкого ценообразования (Dynamic Pricing): 
            Реализован автоматический расчет стоимости билета, интегрирующий три фактора: логистику (базовый тариф за расстояние), 
            комфорт (дифференцированные коэффициенты для верхних/нижних/боковых полок) и социальную нагрузку (автоматический учет 
            льгот для детей и школьников).
            
      Финансовый контур (P&L Report): 
            Спроэктирована модель учета полной себестоимости рейса, включающая переменные расходы (клининг, экипировка бельем, 
            станционные сборы) и постоянные затраты (ФОТ, тяга). Это позволило с высокой точностью рассчитать точку безубыточности 
            рейса и целевую маржинальность.
            
      Интерактивный Dashboard (Инструмент бронирования): 
            Создан пользовательский интерфейс для поиска свободных мест на любом произвольном отрезке маршрута. Система поддерживает
            сложную логику группировки, позволяя находить не только одиночные места, но и полностью свободные купе для семейных 
            поездок, что повышает лояльность клиентов и средний чек.

Технологический стек:
•	Excel: Сложные массивы данных, функции СМЕЩ, ПРОСМОТРX, ИНДЕКС/ПОИСКПОЗ, Умные таблицы, Условное форматирование.
•	SQL (в разработке): Проектирование логики запросов для масштабирования модели на большие данные (Big Data).
•	Python (в разработке): Автоматизация ETL-процессов и построение предиктивных моделей загрузки.
________________________________________
Почему этот проект важен:

Модель наглядно демонстрирует, как при низкой общей загрузке вагона (Load Factor) можно сохранять положительную рентабельность 
за счет высокой сменяемости пассажиров и грамотного управления тарифами на разных участках пути.
